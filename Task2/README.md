# Задание 2. Проверочный лист безопасности для бизнес-систем PropDevelopment

## Цель

Комплексный аудит безопасности IT-систем PropDevelopment для устранения критических проблем:
- Утечка данных между клиентами
- Несанкционированный доступ партнёров к чужим данным 
- API партнёров без единых политик безопасности
- Отсутствие контроля потоков данных между системами

## Охват

**Системы**: 13 систем в 4 доменах
- Домен продаж: Витрина продаж, client-tour-app, client-mart-app, client-crm-app, client-mart-estate-app
- Домен ЖКУ: Витрина сервисов, tenant-core-app, CRM собственников
- Домен финансов: accountant-service-1, Active Directory
- Домен Data: Хранилище данных (Greenplum), BI, DWH (S3)

## Структура deliverables

**security-checklist.md**: Проверочный лист в формате | № | Вопрос | Да/нет | Комментарий |
- 66 проверок в 5 разделах: Управление доступом (16), Безопасность данных (17), Защита инфраструктуры (10), Управление инцидентами (8), Специфические аспекты (15)
- 11 критических проблем отмечены **Нет** для немедленного решения
- Специфичные проверки PropDevelopment отмечены **[PropDevelopment]**

## Критические проблемы требующие немедленного решения (≤ 30 дней)

| № | Проблема | Проверка | Системы |
|---|----------|----------|---------|
| 1 | Клиенты видят данные других клиентов | I.15 (AUTH-002) | client-crm-app, Витрина продаж, client-mart-app |
| 2 | Партнёр УК-А видит данные УК-Б | I.16 (AUTH-003) | tenant-core-app, CRM собственников |
| 3 | Избыточная передача ПДн через API | II.15 (DATA-002) | tenant-core-app → API партнёров |
| 4 | Нет ограничений доступа к Хранилищу данных | II.16 (DATA-006) | Хранилище данных, BI |
| 5 | Несколько точек регистрации клиентов без координации | II.17 (DATA-007) | Витрина продаж, client-crm-app, client-mart-app |
| 6 | Нет единых политик безопасности для API | V.2.1 (API-001) | Все REST API |
| 7 | ИБ-специалист не информирован о изменениях | V.3.1 (VULN-005) | Все команды |
| 8 | Нет логирования доступа к ПДн | IV.7 (LOG-002) | client-crm-app, tenant-core-app, все БД |
| 9 | Нет логирования API запросов партнёров | IV.8 (LOG-006) | tenant-core-app |
| 10 | БД не изолированы от публичного доступа | III.13 (NET-008) | Все БД |
| 11 | CDC трафик не защищён | III.14 (NET-010) | БД → Хранилище данных |
