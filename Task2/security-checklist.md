# Проверочный лист безопасности бизнес-систем PropDevelopment

## Цель проверки
Комплексный аудит безопасности IT-систем PropDevelopment для устранения критических проблем:
- Утечка данных между клиентами (описание кейса PropDevelopment, строка 50)
- Несанкционированный доступ партнёров к чужим данным (описание кейса PropDevelopment, строка 47)
- API партнёров без единых политик безопасности (описание кейса PropDevelopment, строка 45)
- Отсутствие контроля потоков данных между системами (описание кейса PropDevelopment, строка 44)

## Охват проверки

**Системы:**
- **Домен продаж**: Витрина продаж, client-tour-app, client-mart-app, client-crm-app, client-mart-estate-app
- **Домен ЖКУ**: Витрина сервисов для собственников, tenant-core-app, CRM собственников
- **Домен финансов**: accountant-service-1, Active Directory
- **Домен Data**: Хранилище данных (Greenplum), BI, DWH (S3)
- **Инфраструктура**: auth-service-1 (Keycloak), Kubernetes, firewall, все БД
